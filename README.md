## 🔬 Ключевые возможности платформы

1. **Шапка проекта (Hero Section):**
   - Название, авторы, школа, навигация.
   - Ссылка на исследовательский блокнот в [Google Colab](https://colab.research.google.com/drive/1QLS3oyKm5bicvRj0sIfGjEumB6d1oten).
   - Быстрый скролл к клиническому калькулятору F508del.

2. **БЛОК 1: Три этапа исследования:**
   - **Этап 1:** Синтетический прототип на 4000 мутаций (сравнение Gradient Boosting, Logistic Regression, Random Forest).
   - **Этап 2:** Реальные данные ClinVar GRCh38 (4000 вариантов, 1399 генов, 100% совпадение ref с геномом hg38; ROC-AUC = 0.990 комплексной модели против 0.972 у лучшего признака).
   - **Этап 3:** Валидация на новом независимом гене CFTR (129 из 135 вариантов определены верно — точность 95.6%).

3. **БЛОК 2: Система признаков (6 реальных + 2 теоретических):**
   - Переключатель «Биологический смысл» / «Математическая форма».
   - Интерактивный One-Hot Encoding визуализатор последствия мутации $M$.
   - Защита от утечки данных (Data Leakage) при Z-стандартизации: $z = \frac{x - \mu}{\sigma}$ строго по обучающей выборке (`train`).

4. **БЛОК 3: Живой калькулятор Энтропии Шеннона ($H$) и GC-контекста:**
   - Ввод любой последовательности ДНК или выбор из 4 пресетов (включая реальное 50-nt окно муковисцидоза F508del).
   - Подсчёт частот $p(A), p(C), p(G), p(T)$, GC-состава и пошаговая формула $H = -\sum p_i \log_2 p_i$.
   - Честный научный результат: в одиночку энтропия даёт ROC-AUC = 0.579, что подтверждает ценность отрицательных результатов в науке.

5. **БЛОК 4: Калькулятор «Не чёрный ящик» — F508del:**
   - Открытая логистическая формула со стенда:
     $$z = -16{,}3 + 0{,}1 \cdot x_1 + 4{,}7 \cdot x_2 - 1{,}8 \cdot x_3 + 2{,}2 \cdot x_4$$
     $$P(y=1|x) = \frac{1}{1 + e^{-z}}$$
   - Биологическая схема хлорного канала CFTR (норма vs закупорка слизью).
   - Интерактивная ловушка популяционной частоты (The Frequency Trap): почему без учёта рецессивности получается $P = 0.23$, а с коррекцией — верные $P = 0.84$.

6. **БЛОК 5: Интерактивная Матрица Ошибок и Порог $t$:**
   - Реальные показатели Градиентного бустинга при $t = 0.50$: $TN = 363, FP = 100, FN = 111, TP = 226$.
   - Ползунок порога $t \in [0.10, 0.90]$ с сохранением контрольных сумм классов (337 патогенных и 463 доброкачественных).
   - Расчёт 9 метрик с точными дробями (Accuracy, Precision, Recall, F1, Specificity, FPR, FNR, NPV, Balanced Accuracy).

7. **БЛОК 6: Этический дисклеймер и литература:**
   - Дисклеймер об учебном характере и 5 классах ACMG/AMP.
   - Список академических публикаций (NCBI ClinVar, Richards et al. 2015, Shannon 1948, CADD, REVEL, AlphaMissense).

## 🚀 Запуск и сборка

### Локальный запуск в режиме разработки:
```bash
npm install
npm run dev
```

### Сборка production:
```bash
npm run build
```

### Автономная версия (Single-file presentation):
Файл `dist/standalone_presentation.html` содержит всю платформу в одном HTML-файле (~305 КБ) со встроенными скриптами и стилями — его можно открыть в любом браузере двойным кликом даже без интернета и локального сервера!
